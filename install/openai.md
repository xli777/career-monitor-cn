# OpenAI — RC4 installation / Beta test

1. Download `career-monitor-openai-plugin-0.1.0-rc.4.zip` from `downloads/0.1.0-rc.4/`.
2. In a ChatGPT/Codex surface that supports custom Plugins/Skills, upload/install the package or its Skill according to the controls available to your account/workspace.
3. Google Drive is a **separate runtime connection**. The package does not embed another user's connector ID and does not bypass authorization.
4. Grant only the Drive/Docs/Sheets access needed for the candidate workspace.
5. Run a positive activation prompt and an unrelated negative prompt.
6. Test initialization twice; the second run must not duplicate the workspace.
7. Continue through monitoring, recovery, learning, cross-session state and revoke behavior.

Availability depends on plan, workspace, role, region and surface. If the relevant custom Skill/Plugin control is absent, record it as a platform capability gap rather than a Career Monitor job-supply result.
