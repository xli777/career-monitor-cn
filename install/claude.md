# Claude — RC4 installation / Beta test

1. Download `career-monitor-claude-0.1.0-rc.4.zip`.
2. In Claude, open **Customize → Skills**.
3. Choose **+ → Create skill → Upload a skill**.
4. Upload the ZIP and enable the Skill.
5. Test positive and negative activation.
6. Connect Google Drive only when persistent external state is required and available to the target account.
7. Test initialization/idempotency, monitoring, recovery, learning, cross-session continuation and revoke behavior.

Claude Code is an additional runtime and does not substitute for the Claude application Skill upload test.
