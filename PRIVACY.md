# Privacy & Data Handling

## Data locations
- Candidate runtime data: candidate-authorized Google Drive or Feishu workspace.
- Git repository: source code, templates, schemas, tests, fixtures, versions, release artifacts only.
- No candidate passwords, cookies, authorization tokens, private browsing history, or raw candidate private data may be committed.

## Author support
Default is candidate self-use. Support is offered only when the candidate asks or a SUPPORT condition is reached. Issue records remain local by default. A support export requires preview, redaction opportunity, and a second confirmation before the candidate is given a sending method.

## Prohibited handling
- No automatic report sending to the author.
- No password/Cookie storage.
- No credential sharing across platforms.
- No silent write to external state without authorization.
